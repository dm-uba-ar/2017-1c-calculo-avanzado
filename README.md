### Régimen de aprobación

Se deben aprobar dos exámenes parciales. Habrá dos fechas de
recuperación al finalizar el cuatrimestre, una para cada examen. Para
poder ser incluido en las actas de trabajos prácticos, es necesario
haberse inscripto, mediante el [sistema de
inscripciones de la facultad.](http://www.inscripciones.fcen.uba.ar)

### Correlatividades

Para cursar esta materia se deberán tener aprobados los Trabajos
Prácticos de Álgebra Lineal, Análisis II y Taller de Cálculo Avanzado, y
los Exámenes Finales de Álgebra I y Análisis I.

### Importante

Se recuerda que es obligatoria la lectura de las [normas de
higiene y seguridad](http://www.dm.uba.ar/varios/normseg.html).
